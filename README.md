# AI News Summarizer

An AI-powered project that summarizes news articles using Python and Gemini.

This project helps users read news faster by turning long articles into short, clear summaries. It is useful for students, professionals, and anyone who wants quick information without reading full articles.

## What this project does

- Takes input from a news article or article URL
- Uses AI to understand the content
- Extracts the main ideas
- Returns a short and readable summary

## Why this project is useful

Reading news can take a lot of time. This project makes it easier to:
- save time
- understand important points quickly
- get short summaries from large articles

## Technologies used

- Python
- Gemini API
- HTTP requests
- AI-based text summarization

## Features

- Summarizes long news content
- Easy to understand output
- Can be extended with more features later
- Beginner-friendly project structure

## Prerequisites

Before running this project, make sure you have:

- Python 3.10 or above
- Internet access
- A Gemini API key
